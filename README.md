# HR Бот — Оценка кандидатов

Телеграм-бот для HR-команды. Анализирует резюме через Claude AI и выдаёт структурированную карточку кандидата.

## Как работает бот

1. HR пишет /start
2. Выбирает должность из списка
3. Указывает требования (или пропускает)
4. Вставляет текст резюме
5. Получает карточку: балл, вердикт, сильные стороны, риски, вопросы для интервью

## Деплой на Railway

### Шаг 1 — Создай бота в Телеграм
1. Напиши @BotFather в Телеграм
2. Отправь /newbot
3. Придумай имя и username (например hr_ocenka_bot)
4. Скопируй токен вида `7xxxxxxxxx:AAF...`

### Шаг 2 — GitHub
1. Зайди на github.com → New repository → назови `hr-bot`
2. Загрузи все файлы: bot.py, requirements.txt, Procfile

### Шаг 3 — Railway
1. Зайди на railway.app → New Project → Deploy from GitHub
2. Выбери репозиторий `hr-bot`
3. Перейди в Variables и добавь:
   - `TELEGRAM_TOKEN` = токен от BotFather
   - `ANTHROPIC_KEY` = твой ключ sk-ant-...
4. Railway сам запустит бота

### Шаг 4 — Готово
Отправь команду /start своему боту в Телеграм — всё работает!
Поделись username бота с HR-командой.

## Команды бота
- /start — начать новый анализ
- /skip — пропустить требования
- /cancel — отменить текущий анализ
